# Tuya Local Lock（涂鸦本地门锁）

通过局域网直连涂鸦智能门锁，无需云端即可查看门锁状态、电量、开锁记录，并在门铃唤醒窗口内远程开锁。

## 特性

- **纯局域网通信**（基于 [tinytuya](https://github.com/jasonacox/tinytuya)），运行时断外网可用
- **扫码自动配置**：用 Smart Life App 扫码即可获取 Device ID 和 Local Key，无需 Tuya IoT 开发者账号
- **只读状态实体**：门锁状态以 `binary_sensor`（device_class: lock）呈现，避免误触
- **门铃唤醒开锁**：独立 `button` 实体，仅门铃唤醒后 20 秒内可操作，休眠时自动禁用
- **适配电池门锁**：设备休眠时正常展示状态，唤醒后自动抓取最新 DPS
- **开锁记录**：支持指纹、人脸、密码、卡片、APP 等多种方式，可将「编号」映射为成员名称
- **门磁联动**：接入门磁传感器后自动同步锁状态，并识别室内机械开门写入开锁记录
- **门铃事件独立识别**，不与开锁事件混淆
- **HA 事件总线输出**，方便编写自动化通知
- **内置广播调试工具**（原始报文 / 解密明文 / TCP 推送探测），便于排查适配问题

## 安装

### HACS（推荐）

1. HACS → 集成 → 右上角「⋮」→ 自定义存储库
2. 填入仓库地址 `https://github.com/tz-yang/local_lock_tuya`，类别选 **Integration**
3. 搜索并安装 **Tuya Local Lock**
4. 重启 Home Assistant

### 手动安装

将 `custom_components/tuya_local_lock` 目录复制到 HA 配置目录的 `custom_components/` 下，然后重启。

## 添加设备

### 方式一：扫码获取（推荐）

1. 设置 → 设备与服务 → 添加集成 → 搜索 **Tuya Local Lock**
2. 选择「扫码获取（Smart Life）」
3. 输入 Smart Life 用户码（App → 我的 → 设置 → 账号与安全 → 用户码）
4. 用 Smart Life App 扫描页面显示的二维码，点击「确认登录」
5. 从设备列表中选择门锁，Device ID 和 Local Key 会自动填入
6. 完成连接验证即可

> 扫码登录仅用于一次性获取本地密钥，运行时完全不依赖云端。

### 方式二：手动填写

需要三个信息：

| 信息 | 获取方式 |
|---|---|
| Device ID（设备 ID） | 涂鸦 IoT 开发平台 → 设备列表，或用 tinytuya Wizard 扫描 |
| Local Key（本地密钥） | 涂鸦 IoT 开发平台 → 设备详情；也可用 tinytuya Wizard 获取 |
| IP 地址 | 路由器里查看门锁 IP；留空则自动扫描发现 |

> 门锁是电池供电、平时休眠，添加时即使暂时连不上也允许保存，唤醒后会自动验证。

## 配置说明

集成支持 UI 配置（设置 → 设备与服务 → Tuya Local Lock → 配置）。

### 连接设置（首次添加）

| 项目 | 说明 |
|---|---|
| 设备名称 | 实体显示名称 |
| Device ID | 涂鸦设备 ID |
| Local Key | 本地通信密钥 |
| IP 地址 | 留空自动发现 |
| 协议版本 | 以设备实际协议为准，常见为 3.3；可在广播调试中查看设备上报的 version |

### 门锁 DP 设置（选项）

| 项目 | 说明 |
|---|---|
| 状态 DP 编号 | 锁状态功能点编号；只推送开锁事件的锁填 `0` |
| 状态 DP 为 true 时表示已上锁 | 按设备极性调整 |
| 控制 DP 编号 | 发送上锁/解锁指令的功能点，默认 1 |
| 上锁/解锁发送的值 | 默认 true / false |
| 临时开门 DP 编号 | 支持「开门」（短暂解锁）时填写，0 = 不启用 |
| 电量 DP 编号 | 剩余电量百分比功能点，0 = 不启用 |
| 解锁记录 DP 列表 | 推送开锁事件的 DP 编号，多个用英文逗号分隔，如 `1,7` |
| 成员编号映射 | 把 DP 值翻译成名称（见下） |
| 门铃 DP 编号 | 门铃 Boolean 功能点编号，0 = 不启用 |
| 自动回锁延迟 | 开锁事件后 N 秒状态自动回到「已锁定」，0 = 关闭 |
| 轮询间隔 | 状态拉取周期（秒），默认 60 |

### 门磁与机械开门识别

| 项目 | 说明 |
|---|---|
| 外部状态来源实体 | 填入门磁等 `binary_sensor` 的实体 ID。启用后门锁显示状态由该实体决定（on = 门开 = 已解锁，off = 门关 = 已锁定） |
| 反转外部状态 | 若门磁 on 表示门关，勾选后反转 |
| 门磁识别机械开门并记录 | 开启后，门磁检测到开门且无电子开锁信号时，写入「最近开锁」 |
| 手动开锁显示名称 | 机械开门在记录中的显示名称，默认「手动开锁」 |
| 竞态窗口 | 门磁开启后等待电子开锁信号的秒数，默认 2 |
| 电子会话超时 | 电子开锁先到但门没开时，关闭会话的超时秒数，默认 5 |

### 成员编号映射

每种开锁方式推送的值是成员/方式编号。映射格式为每行一条：

```
1=爸爸（指纹）
2=爸爸（人脸）
3=保姆（指纹）
7=一次性密码
```

未配置映射的编号直接显示原始值。

## 实体与事件

### 实体

| 实体 | 说明 |
|---|---|
| `binary_sensor.*` | 门锁状态（只读）；on = 已解锁，off = 已锁定。属性含 `dps`、`operable`、`external_state_value` 等 |
| `button.*_网络开锁` | 网络开锁按钮；仅门铃唤醒后 20 秒内可用，休眠时自动不可用 |
| `sensor.*_电量` | 剩余电量百分比 |
| `sensor.*_开锁信号` | 每次开锁产生「待机 → 成员名称」变化（3 秒复位），适合状态触发器 |
| `sensor.*_最近开锁` | 最近一次开锁记录；属性含 `dp`、`raw_value`、`display`、`count`（累计次数） |
| `sensor.*_门铃` | 门铃触发时变为「门铃」（3 秒复位） |
| `sensor.*_广播调试` | 原始广播（hex）、持久化历史、TCP 推送帧 |
| `sensor.*_广播明文` | 只展示解密后的广播内容 |

### 事件

| 事件类型 | 数据字段 |
|---|---|
| `tuya_local_lock_unlock_event` | `dp`、`raw_value`、`display`、`count` |
| `tuya_local_lock_doorbell_event` | `dp` |

### 服务

| 服务 | 说明 |
|---|---|
| `tuya_local_lock.set_lock_state` | 手动设置门锁显示状态（`locked: true/false`） |

自动化示例：

```yaml
automation:
  - alias: 门锁开锁通知
    trigger:
      - platform: event
        event_type: tuya_local_lock_unlock_event
    action:
      - service: notify.mobile_app_phone
        data:
          title: "门锁"
          message: "{{ trigger.event.data.display }} 已开锁"
```

## 门铃唤醒开锁机制

电池门锁休眠时不接受网络连接：

1. 访客按门铃 → 门锁唤醒并广播
2. 集成收到广播后开启 **20 秒操作窗口**，`button.*_网络开锁` 变为可用
3. 窗口内按下开锁按钮 → 立即发送成功
4. 窗口结束 → 按钮自动禁用

典型用法：门铃事件触发手机通知 → 通知中附带开锁操作，在窗口内点击即可远程开门。

## 机械开门识别原理

涂鸦门锁在室内机械开门（旋转把手）时通常不推送任何 DP，仅有门磁能感知。集成通过四态状态机区分电子开门与机械开门：

- 门磁开启后，在竞态窗口（默认 2 秒）内收到电子开锁信号 → 判定为电子开门，不重复记录
- 超时无信号 → 判定为室内机械开门，写入「最近开锁」
- 电子开门期间（门一直开着）不会误报
- 门关闭（门磁 on→off）后重新武装，下一次开门才会再次判定

## 如何查找 DP 编号

1. **扫码配置时**：设备详情中可查看所有 DP 的 code 与编号映射
2. **涂鸦 IoT 平台**：设备 → 功能点 / 设备调试日志，功能点 ID 即 DP 编号
3. **门锁实体属性**：唤醒后查看 `dps` 快照，根据值反推编号（如电量 66 对应的键）
4. **实测法**：刷指纹 / 按门铃后，对比 `dps` 中新增或变化的键

> 注意区分：DP **编号**（功能点，如 1）和 DP **值**（成员编号，如 2）。解锁记录 DP 列表填的是编号。

## 调试选项

在选项中开启：

| 开关 | 作用 |
|---|---|
| 调试：捕获广播原始报文 | 最近 50 条广播（含 hex 和解码结果）存入内存 |
| 保存广播历史 | 广播持久化到 `.storage`，重启不丢，上限 200 条 |
| 探测 TCP 主动推送帧 | 唤醒时建立持久连接静默监听 12 秒，验证设备是否会主动推送状态帧 |

也可以在集成卡片菜单中「启用调试日志」，实时查看详细日志（无需修改 configuration.yaml）。

## 常见问题

**实体显示「不可用」**
门锁休眠且从未成功连接。按门铃唤醒后会自动抓取状态；同时确认协议版本是否正确（错误时日志报 `Error 914`）。

**云端有开锁记录，HA 没有**
依次检查：①「解锁记录 DP 列表」是否填了正确的 DP 编号；②开锁是否发生在集成重载期间；③开启广播调试后确认设备是否在局域网发送数据。

**开锁按钮点不动**
按钮仅在门铃唤醒后 20 秒内可用。请先按门铃唤醒门锁，再操作。

**同一人连续刷同一枚指纹，只记录一次**
同一次唤醒会话内的多次抓取只计一次；关门后再次开锁属于新会话，会正常计数。
